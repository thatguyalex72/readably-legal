# readably-legal

The privacy policy, support page and terms for **Offtext**, published with GitHub Pages.

This repository is public **only so GitHub Pages can serve it**. The app's source is
private and lives elsewhere. Nothing here is secret and nothing here should be.

## Editing

Plain HTML, one shared stylesheet, no build step and no dependencies. Edit and push; Pages
redeploys in a minute or so.

The public support address is `support@offtext.app` (set 2026-11-11). It forwards to a private
inbox, so changing where mail lands needs no edit here.

## Keeping it honest

The privacy policy makes specific factual claims about the app — no analytics, no third-party
SDKs, Notion tokens in the Keychain, diagnostics never synced. Those were true when written
and are checkable in the source. **If the app's behaviour changes, this changes with it**, in
the same commit where possible.
